# ULTRON Orb UI - Android APK

## Setup

```bash
npm install
eas login
npm run build:android
```

## Features
- 3D Holographic Orb
- Expo + React Native
- Ready for Android APK

## Build & Install

1. Run `npm run build:android`
2. Wait 10-15 minutes
3. Download APK
4. Send to phone
5. Install and launch!
